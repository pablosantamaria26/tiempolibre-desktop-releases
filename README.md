# Tiempo Libre San Bernardo — App de escritorio

Instalador de la app de escritorio para Windows 10/11.

**Descargar:** entrá a [Releases](../../releases/latest) y bajá `Tiempo-Libre-Setup-x.y.z.exe`.

Una vez instalada, la app se actualiza sola cada vez que se abre: no hace falta volver a descargar nada.

> Este repositorio solo publica los instaladores. No contiene código fuente.
